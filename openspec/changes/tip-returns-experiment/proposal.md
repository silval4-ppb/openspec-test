# Proposal

## Why

To add the potential return on the Call to Action of the Bet Builder module, which we hypothesise will reduce friction for customers to understand odds for those type of bets.

## What Changes

Adds a label below the Add to Betslip text on the Tip CTA that describes the potential returns from the bet.

The change should be gated by an experiment.

The experiment variants are yet to be defined, but at least one variant with the new label and the default variant without any change.

## Capabilities

### New Capabilities

- `tip-cta-returns-label`: Shows the potential returns below the Add to Betslip text on the Tip CTA.

### Modified Capabilities

None.

## Impact

- Tip CTA label and experiment configuration.
