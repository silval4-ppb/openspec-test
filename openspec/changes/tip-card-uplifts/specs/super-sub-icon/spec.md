# Spec Delta

## Purpose

Defines the icon shown on a Tip Card part when it is marked as Super Sub enabled.

## ADDED Requirements

### Requirement: Super Sub tips use the updated icon
When a tip is marked as a Super Sub, its Tip Card SHALL display the updated Super Sub icon from the Design System.

Presentation can be seen in: https://www.figma.com/design/68m6tNqiRpi2uN1Izhuhe7/The-Feed--%3E-Iteration-1.2?node-id=15916-301202&m=dev

#### Scenario: When a Tip Part has Super Sub Enabled
- **WHEN** a Tip Card displays a tip part that has super sub enabled 
- **THEN** the card displays the updated Super Sub icon
