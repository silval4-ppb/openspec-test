# Spec Delta

## Purpose

Defines how Tip Cards present single-leg and multi-leg tips.

## ADDED Requirements

### Requirement: Single-leg tips use the single-leg presentation
Singles and events with one leg SHALL use the new single-leg Tip Card presentation.

Presentation can be seen in: https://www.figma.com/design/68m6tNqiRpi2uN1Izhuhe7/The-Feed--%3E-Iteration-1.2?node-id=15916-301202&m=dev

#### Scenario: Single or one-leg event is presented
- **WHEN** a Tip Card represents a single or an event with one leg
- **THEN** it uses the single-leg presentation

### Requirement: Multi-leg tips use the multi-leg presentation
Multis and events with more than one leg SHALL use the multi-leg Tip Card presentation.

Presentation can be seen in: https://www.figma.com/design/68m6tNqiRpi2uN1Izhuhe7/The-Feed--%3E-Iteration-1.2?node-id=15916-301202&m=dev

#### Scenario: Multi or multi-leg event is presented
- **WHEN** a Tip Card represents a multi or an event with more than one leg
- **THEN** it uses the multi-leg presentation
