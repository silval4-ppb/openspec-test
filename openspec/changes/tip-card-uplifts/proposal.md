# Proposal

## Why

After Feed moving to the new TBD platform in the scope of Oasis we want to do some uplifts to the visual look of the Tip Card.

## What Changes

- new Tip Card border
- change the Super Sub Icon.
- change how Singles or Event with only one leg is shown.
- change how Multis or Event with more than one leg is shown.

## Capabilities

### New Capabilities

- `tip-card-border`: Defines the visual border treatment for Tip Cards.
- `super-sub-icon`: Defines how the Super Sub icon is presented on Tip Cards.
- `tip-card-leg-layout`: Defines how single-leg and multi-leg events are presented on Tip Cards.

### Modified Capabilities

None.
