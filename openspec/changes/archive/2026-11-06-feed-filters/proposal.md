# Proposal

## Why

Allowing the User to filter the Feed's tips for discoverability.

## What Changes

Adding a Filter capability in the Feed View page. The TIPS service allows filters in the Feed query.

## Capabilities

### New Capabilities
- `filter-by-profile-type`: Filtering by [Profile Type](../../../knowledge/capabilities/social/profile-type.md)
- `filter-by-profile-id`: Filtering by Profile Ids
- `filter-by-tip-status`: Filtering by [Tip Status](../../../knowledge/capabilities/social/tip-status.md). It can be `COPYABLE` or `INACTIVE`

### Modified Capabilities

## Impact

- TIPS Service
- Feed FE Component
